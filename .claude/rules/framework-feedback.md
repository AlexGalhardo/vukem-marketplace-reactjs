# Framework feedback rule

This project is the battle test for vukem 1.0. Every vukem bug, missing feature, awkward API, security issue or wrong/missing docs page you hit gets one entry appended to `vukem-feedback.md` at the repo root (format at the top of that file; include the docs URL for docs findings). Apply a local workaround, note it with `// workaround(vukem): <entry title>` in code, and keep going. Never edit the vukem repo from here.
