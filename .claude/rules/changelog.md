# Changelog rules

- Keep a Changelog 1.1.0, SemVer tags `vX.Y.Z`, generated by git-cliff (`cliff.toml`) from Conventional Commits: every entry links its commit. Do not edit `CHANGELOG.md` by hand; write a good commit message instead (`feat` → Added, `fix` → Fixed, `refactor`/`perf` → Changed; `docs`/`test`/`ci`/`build`/`chore` are left out).
- Releasing: `git cliff --tag vX.Y.Z -o CHANGELOG.md`, commit `chore(release): vX.Y.Z`, annotated tag `vX.Y.Z`, push the commit and the tag; `release.yml` builds the GHCR image and publishes the GitHub release with that section.
- Never move a pushed tag.
